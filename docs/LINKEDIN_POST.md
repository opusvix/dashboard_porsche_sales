# Post para o LinkedIn

🏎️ Novo projeto no meu portfólio: **Porsche Enterprise Sales Intelligence**

Desenvolvi um dashboard executivo de vendas voltado à análise de desempenho comercial, reunindo indicadores como veículos vendidos, receita, ticket médio, modelos líderes, cidades de destaque, Model Year e métodos de pagamento.

O projeto foi estruturado para oferecer uma experiência próxima a uma solução corporativa de Business Intelligence, com:

✅ filtros compartilhados e persistentes  
✅ comparação com o período anterior  
✅ drill-through por cidade e modelo  
✅ heatmap Cidade × Modelo  
✅ tooltips analíticos  
✅ insights automáticos  
✅ detalhamento transacional e exportação para CSV  
✅ layout responsivo

A base contém 100 registros sanitizados, com tratamento específico para preservar a confiabilidade das análises temporais.

Este trabalho também foi uma experiência prática de **desenvolvimento assistido por Inteligência Artificial**. O dashboard contou com o apoio do **ChatGPT/Codex da OpenAI** na evolução da interface, implementação das interações, revisão técnica e documentação. Minha atuação esteve na definição das perguntas de negócio, KPIs, regras analíticas, direcionamento do projeto e validação dos resultados.

Essa colaboração mostrou como a IA pode ampliar a produtividade do profissional de dados sem substituir o pensamento crítico, o conhecimento do negócio e a responsabilidade sobre as decisões.
